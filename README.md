# My Portfolio

A modern, responsive portfolio website showcasing my projects and skills.

## Features

- **Responsive Design**: Works seamlessly on desktop, tablet, and mobile devices
- **Navigation**: Easy-to-use navigation bar with smooth scrolling
- **About Section**: Highlights skills and experience
- **Projects Showcase**: Display your best work with project cards
- **Contact Section**: Links to social media and contact information
- **Modern UI**: Clean and professional design with smooth animations

## Sections

1. **Home/Hero**: Eye-catching introduction section
2. **About**: Brief introduction and skills showcase
3. **Projects**: Grid layout of your projects with descriptions
4. **Contact**: Links to reach out via various platforms
5. **Footer**: Copyright and additional information

## Technologies Used

- HTML5
- CSS3
- Responsive Design with CSS Grid and Flexbox

## Getting Started

1. Clone this repository
2. Open `index.html` in your web browser
3. Customize the content with your information
4. Update project details and links

## Customization

- Edit `index.html` to update content
- Modify `style.css` to change colors and styling
- Update the color variables in `:root` to match your brand
